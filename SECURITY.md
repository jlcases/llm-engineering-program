# Seguridad

No publiques secretos, datos personales, prompts de clientes ni vulnerabilidades explotables en
un Issue. Para un problema de seguridad usa **Security → Report a vulnerability** en GitHub e
incluye la ruta afectada, impacto, reproducción mínima y una mitigación si la conoces.

Solo `main` recibe correcciones de seguridad. Los labs deben funcionar con datos ficticios y no
deben enviar información fuera del equipo sin una acción explícita de quien los ejecuta.
