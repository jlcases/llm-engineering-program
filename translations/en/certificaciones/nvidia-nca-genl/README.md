# NVIDIA Certified Associate — Generative AI LLMs (NCA-GENL)

Review path for the NVIDIA Certified Associate in Generative AI and LLMs. Compare the scope and requirements with the [official certification page](https://www.nvidia.com/en-us/learn/certification/generative-ai-llm-associate/) before scheduling the exam.

## Current Blueprint

The official page, verified on **August 21, 2026**, weights five areas: Core Machine Learning and AI Knowledge (30%), Software Development (24%), Experimentation (22%), Data Analysis and Visualization (14%), and Trustworthy AI (10%). NVIDIA also lists ten study topics; these topics are not ten equally weighted domains.

## Available Materials

- [Area and topic guide](guia-blueprint.md): concept map, key decisions, and common errors.
- [Topic flashcards](flashcards.md): active recall and spaced repetition.
- [50-question practice exam](simulacro-50-preguntas.md): timed practice with explanations for the correct option and the distractors.

## Recommended Path

1. Read each topic after completing the program module that covers it, and relate it to its weighted area.
2. Pass its flashcards to the spaced repetition system you use.
3. Take the practice exam in a single session and tag each failure by area and cause:
   lack of knowledge, confusion between concepts, or incomplete reading of the scenario.
4. Repeat the failed questions without memorizing the letter: first explain the decision rule.

As an internal criterion, aim for a sustained global score of 80% and the ability to justify why the other three options are inferior. This material is original and does not contain real exam questions.
